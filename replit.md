# Glee-fully Chai Chasers

A cozy cosmic slot game where two opinionated cats — Joey and Phoebe — guide players through a fully designed game ecosystem, from a storybook opening through seven distinct bonus experiences, all wrapped in a coherent Pacific Northwest midnight brand.

## Project overview

Monorepo managed by pnpm. Artifacts:
- `artifacts/chai-chasers` — main playable slot game (React + Vite)
- `artifacts/chai-chasers-slides` — portfolio/pitch deck
- `artifacts/chai-chasers-video` — animated video showcase
- `artifacts/api-server` — backend API
- `artifacts/mockup-sandbox` — design canvas scene previews (40+ scenes)

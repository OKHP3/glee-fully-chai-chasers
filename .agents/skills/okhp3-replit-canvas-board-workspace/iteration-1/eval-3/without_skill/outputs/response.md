# Closing a Canvas Layout Session for a Designathon Submission

## Goal
Ensure judges see a fully organised, presentation-ready canvas the moment they open it — no panning, no hunting for content, no collapsed frames.

---

## Step-by-Step Conventions

### 1. Finalise All Frame & Layer Names
- Rename every frame, group, and layer to something descriptive (e.g. `01_Hero`, `02_Problem`, `03_Solution`).
- Use a consistent numbering prefix so the layer panel reads as a natural story from top to bottom.

### 2. Group & Align Content Logically
- Ensure related elements are grouped inside clearly labelled frames.
- Use the alignment tools to make sure nothing is accidentally off-grid or overlapping unintentionally.
- Lock any decorative/background elements so judges can't accidentally move them.

### 3. Set a Consistent Grid / Layout Order
- Arrange frames left-to-right (or top-to-bottom) in the order you want them read.
- Leave consistent spacing between frames (e.g. 100–200 px) so the canvas feels breathable when zoomed out.

### 4. Collapse All Expanded Layer Groups
- In the layers panel, collapse every group/frame so judges see a clean top-level list, not a sprawling tree.

### 5. Add a "Start Here" Cover Frame (Optional but Recommended)
- Place a clearly labelled cover frame at the far left (position 0,0) that names your project, team, and submission date.
- This is the first thing judges see when the canvas loads.

### 6. **The Critical Final Step — Set the Viewport / Default View**

> **This is the most important closing action.**

In virtually every major canvas tool (Figma, FigJam, Miro, Figjam, Canva whiteboards, etc.) you must **save/lock the camera position and zoom level** so it is restored exactly when anyone opens the link:

#### In Figma / FigJam
1. Zoom and pan until the canvas shows exactly what you want judges to see first (e.g. your cover frame or the full board at a readable zoom).
2. Press **`Shift + 1`** ("Zoom to fit all frames") or manually set your preferred zoom/position.
3. In presentation/prototype mode, set the **Starting Frame** to your cover frame:  
   *Prototype tab → Flow starting point → select your cover frame*.
4. Share the file link. Figma restores the last-saved view for viewers.

#### In Miro
1. Pan and zoom to the desired overview.
2. Use **"Set as default view"** (right-click the canvas background → *Set current view as default*).
3. This saves the viewport so anyone opening the board lands exactly there.

#### In FigJam / Whiteboard tools (general)
- Look for **"Set default view"** or **"Save current view"** in the board settings or right-click menu.
- Some tools call it **"Home view"** or **"Starting position"**.

#### In Canva Whiteboards
1. Arrange your content, zoom to fit.
2. Hit **Share → Present** and set the first slide/frame as your entry point.

## Summary Checklist Before Submission

| # | Action | Done? |
|---|--------|-------|
| 1 | All frames named & numbered | ☐ |
| 2 | Layers grouped & locked decoratives | ☐ |
| 3 | Frames ordered left-to-right | ☐ |
| 4 | Layer panel collapsed | ☐ |
| 5 | Cover / title frame at position 0,0 | ☐ |
| **6** | **Default/home view set to show full organised layout** | **☐** |
| 7 | Shareable link tested in incognito window | ☐ |

---

## The Golden Rule
> **Always open your own submission link in a private/incognito browser window after closing it.** This is the exact experience a judge will have. If the canvas lands on your intended view — you're done.

The final, non-negotiable step is **setting and verifying the default viewport** so the canvas opens exactly as intended, every time.
